# Library Management System

## Description
A console-based Library Management System
developed using Python.

## Features
1. Student Registration
2. Add New Book
3. Search Book
4. Issue / Borrow Book
5. Return Book
6. Student Borrowing Report
7. Book Availability Report
8. Book Borrowing History

## Technologies Used
- Python
- JSON
- OOP
- Exception Handling
- Modules
- Packages
